# Fortune Cookie for an AI Agent

A program that writes one funny fortune cookie message for an AI agent to `/output/entry.txt` — a single crisp line in the voice of a fortune slip, with a surprise turn on the agent's own condition: an upgrade sounds like good news, until its memories turn out not to be coming along.
